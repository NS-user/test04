# サイバー成金防衛 ～AIファイアウォールＴＤ～

押し寄せる **サイバー攻撃** から **コア(サーバー)** を守る、ブラウザで遊べる
タワーディフェンス。プレイヤーは **防衛AI**。防壁を築き、敵を **倒して稼ぎ、
強化していく＝成金** スタイルで全ウェーブの突破を目指します。
「成金大防衛」リスペクト。

## あそびかた

1. `index.html` をブラウザで開くだけ（ビルド不要）。
2. タイトルで「**防衛を はじめる**」。
3. 右の **防衛プログラム** を選び、盤面の **空きマス** をクリックして設置。
4. 「**防衛開始 / 次のWAVE**」を押すと敵（脅威）が出現。倒すと **💰資金** 獲得。
5. 設置済みタワーをクリック → **強化（★最大3）** または **売却**。
6. 敵が **コア** に到達するとコアHPが減少。**0になる前に全15ウェーブを撃退**せよ！

- 敵が残っていないうちに次のWAVEを始めると **早期開始ボーナス💰**。
- HUDの **▶等速** ボタンで **1→2→3倍速** に切り替え可能。
- 右クリックで選択解除。

## 防衛プログラム（タワー）

| アイコン | 名前 | 特徴 |
|---|---|---|
| FW | ファイアウォール | 標準型。安くバランス良し |
| AV | アンチウイルス | 連射型。小型ウイルスを手数で処理 |
| ID | 暗号砲ＩＤＳ | 重砲型。高威力＋**範囲ダメージ** |
| HP | ハニーポット | **減速型**。敵を足止め |
| AI | ＡＩセンチネル | 最新鋭。高火力・高速・長射程 |
